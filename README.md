# Encantos Literários - Clube de Assinatura

## Sobre o projeto

Landing page para o clube de assinatura **Encantos Literários**. A página apresenta a proposta do clube, os itens que compõem o kit mensal e os planos de assinatura disponíveis. O projeto conta com animações de entrada, interações por hover e layout responsivo. Foi desenvolvido como parte da **formação Full Stack da Rocketseat**.

[Preview do projeto](https://github.com/isabellesouzasv/clube-de-assinatura/blob/main/assets/screenshot.png) ([image](https://github.com/isabellesouzasv/clube-de-assinatura/raw/main/assets/screenshot.png))

## Funcionalidades

- Apresentação do clube de assinatura e de sua proposta literária.
- Hero com animação de entrada e chamada para assinatura.
- Seção interativa sobre os benefícios do clube.
- Apresentação animada dos itens presentes no kit mensal.
- Exibição do livro, broche exclusivo e marcadores temáticos.
- Planos de assinatura mensal, semestral e anual.
- Destaque automático para o plano semestral.
- Alteração da cor do plano conforme o card apontado pelo usuário.
- Links para redes sociais e páginas institucionais.
- Layout responsivo para desktop, tablet e dispositivos móveis.
- Suporte à preferência de movimento reduzido do sistema.

## Tecnologias

## Como executar

Basta abrir o arquivo `index.html` no navegador. Não há dependências ou instalação necessárias.

Para clonar o projeto:

```bash
git clone https://github.com/isabellesouzasv/clube-de-assinatura.git
cd clube-de-assinatura
```

Depois, abra o arquivo:

```text
index.html
```
